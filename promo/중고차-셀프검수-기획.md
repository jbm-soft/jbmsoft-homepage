# 중고차 셀프검수 키트 기획 (내부)

공개 페이지에 없는 메모입니다. 검색량 숫자는 측정하지 않아 적지 않습니다. 설치·전환·순매출 시나리오는 만들지 않습니다. 나중에 내부 계산이 필요하면 문장 앞에 `가정:`을 붙이고 이 문서에만 둡니다.

## 한 줄

중고차 한 대를 살 때, 성능점검기록부 사진을 쉬운 말로 읽고 현장 기록과 견적 항목을 정리하는 안드로이드 앱. 개발사는 JBM SOFT. 정비 진단을 대신하지 않음.

## MVP (한 대, 첫 출시 범위)

- 성능점검기록부 촬영. 필요한 권한은 카메라.
- 항목마다 서류 단어를 유지한 채 쉬운 말로 풀이. “양호”를 무사고 판정으로 바꾸지 않음.
- 사용자가 직접 본 보험이력·자동차365와 기록부를 나란히 적는 체크리스트. 앱이 두 사이트를 대신 조회한다고 말하지 않음.
- 현장 사진 순서와 시운전 때 표시할 항목. 리프트·진단기·도막 측정을 대신하지 않음.
- 견적서의 매도비, 관리비용, 취득세가 서로 다른 항목임을 읽어 줌. 세액 확정·절세 자문 없음.
- 기록부 표기와 실차가 다르면 사진과 기록부를 한 PDF로 묶어 성능보증 문의 자료로 씀. 청구 대행·성공 보장 없음.
- 사진→PDF 묶음은 증거정리와 같은 발상을 재사용할 수 있음. 공개 페이지에서는 “한 PDF로 묶는다” 수준만.

## 면책 (공개 페이지에 유지)

- 사고 여부를 판정하거나 보장하지 않음. “사고차가 아니다”를 약속하는 문장 금지.
- 정비사·리프트·진단기를 대신한다는 문장 금지. 부정문(“대신하지 않습니다”)만 사용.
- 법률 자문·세무 상담 아님. 취득세율 숫자를 페이지에 만들지 않음.
- 성능보증 청구의 기간·금액·성공을 단정하지 않음. 기한 숫자는 보증서에 있다고만 안내.
- 스토어 출시 전. 가짜 Play 버튼 없음.
- 내부 매출·설치·전환 숫자를 공개 페이지에 두지 않음.
