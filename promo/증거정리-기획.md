# 대화모아 기획 (내부, 옛 가칭 증거정리)

공개 페이지에 없는 메모입니다. 검색량 숫자는 측정하지 않아 적지 않습니다. 매출 시나리오 숫자도 만들지 않습니다. 나중에 내부 가정이 생기면 이 문서에만 두고, 문장 앞에 `가정:`을 붙입니다. 사이트·OG·광고 문구로 옮기지 않습니다.

## 한 줄

안드로이드에서, 카카오톡 공식 내보내기 파일(txt·zip)을 공유받아 제출용 형식의 대화 PDF로 정리하는 앱. 개발사는 JBM SOFT.

## MVP (첫 출시 범위)

- 입력: 사용자가 카카오톡에서 직접 내보낸 txt 또는 zip. 공식 내보내기는 PDF가 아님.
- 공유 시트로 앱에 전달.
- 출력 PDF
  - 날짜·시각
  - 사진은 파일명이 아니라 페이지에 삽입
  - 쪽 번호
  - 원본 파일 SHA-256
  - 별표한 메시지를 갑 제○호증 형식의 표로 모음 (정리용 번호)
- 처리: 기기 안. 서버 업로드 없음. SMS 권한·접근성 권한 없음.
- 스토어 등록 전. 패키지명, 리뷰, 설치 수를 공개하지 않음.

## 이후 단계 (MVP에 넣지 않음)

- 갤럭시 통화 녹음 파일의 녹취 초안. 파일당 유료. 금액 미정.
- 음성 인식(STT)은 이 단계에 속함. 대화 PDF와 분리해 안내.

## 포지션

형식 변환·정리 도구. 법적 효력, 채택, 승소를 말하지 않음. 앱 이름·아이콘에 카카오/Kakao를 넣지 않음. 설명 문구의 “카카오톡에서 내보낸 대화”는 허용. 카카오 로고·노란색 말풍선 트레이드드레스를 흉내 내지 않음.

## 키워드 (검색량 없음)

- 카톡 대화 PDF
- 카톡 대화 인쇄
- 카톡 증거
- 카카오톡 대화 내보내기
- 대화 내용 내보내기 txt zip

## 면책 (공개 페이지에 유지)

- 정리 도구이며 법적 효력을 만들지 않음.
- 제출 형식의 허용은 제출처 기준.
- 카카오 앱이 아니고 제휴·보증이 없음.
- 공식 내보내기는 txt·zip. 카카오톡이 PDF를 만들어 주지 않음.
- 대화 PDF는 온디바이스. 녹취·STT는 이후, 파일당 유료, 가격 숫자 없음.
- Google Play 링크, 가짜 설치 버튼, 별점, 다운로드 수를 두지 않음.
- “플레이 스토어에 경쟁 앱이 없다”를 공개 페이지에 쓰지 않음.

## 사실로만 적을 다른 서비스

- EZPZ File (웹). 칼럼이 PDF의 사진은 파일명이라고 안내하고, 사진은 HTML 저장 후 인쇄를 따로 설명. https://ezpzfile.com/ko/column/chat-to-pdf-print
- 법짝 증거수집기. PC·브라우저 전문가 도구. https://bubjjak.com/evidence
- NoCutoff. 공개 한국어 목록에 카카오톡이 없고, 긴 작업은 대화 전체 $5부터. https://nocutoff.com/ko/
- LightOn. 녹취록. 대화 PDF가 본문이 아님. https://law-transcript.lightonpluslab.com/

비교는 환경 차이만. 비하 문구 금지.
