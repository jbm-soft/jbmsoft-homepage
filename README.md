# JBM SOFT Corporate Website

Official corporate website and portfolio platform for **JBM SOFT (제이비엠 소프트)** — showcasing 8+ years of web, mobile app, and business automation projects.

🌐 **Live:** [https://jbmsoft.co.kr](https://jbmsoft.co.kr)

---

## ✨ Key Features

- **Portfolio Showcase:** Interactive filtering across Web, Commerce, Mobile App, Automation, Game, Security, and AI categories
- **Utility Tools & Guides:** Built-in web utilities and practical development/business guides
- **Responsive & Animated UI:** Built with Tailwind CSS v4 and Framer Motion
- **SEO & Performance:** Next.js App Router with Turbopack

---

## 🛠 Tech Stack

- **Framework:** Next.js 15 (`15.5.4`) with Turbopack
- **UI:** React 19, Tailwind CSS v4, Framer Motion
- **Language:** TypeScript 5
- **Deployment:** Netlify (`netlify.toml`)

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📁 Project Structure

```text
src/
├── app/          # Next.js App Router pages & layouts
├── components/   # Reusable UI components
├── data/         # Site config, portfolio items, tools, and guides
└── lib/          # Shared helpers and utilities
```
